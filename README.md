An agent-assisted data-mining project that turns twelve months of raw retail transactions into a capacity-bounded, auditable customer action list: **segment → predict churn → recommend cross-sell → prioritise under a campaign budget.**

## What this project does

Retailers record every transaction but often cannot answer an operational question: *which customers should we retain, which should we grow, and with which products?* This project builds one integrated analysis on the UCI Online Retail dataset (541,909 lines, Dec 2010–Dec 2011):

1. **Customer segmentation** — K-means on behavioural features, with elbow, silhouette and bootstrap stability (K = 5 descriptive segments).
2. **Churn prediction** — logistic regression, decision tree and random forest, trained on a T1 cohort (as of 2011-05-31), validated by 5-fold cross-validation, a held-out split and a T2 out-of-time cohort (as of 2011-08-31).
3. **Association rules** — FP-Growth cross-sell rules mined on Dec 2010–Jul 2011 and validated on an Aug–Dec 2011 holdout.
4. **Similarity & distance** — cosine lookalike customers and item-item similar products.
5. **Integrated decision framework** — a segment × risk matrix, a priority score (churn probability × monetary value), a top-200 pilot target list and an explicitly illustrative ROI model.

| Selected churn model | logistic regression (chosen on validation PR-AUC) |
| Out-of-time ROC-AUC (T2) | 0.7392 |
| Top-decile targeting lift | 1.6916× over random contact |
| Pilot campaign (top 200) | conservative validated net expected value GBP 14802.58; model-precision optimistic bound GBP 33799.89 |
| Random-200 baseline | net GBP 1925.76; model uplift GBP 31874.13 |
| Business rules | 593 rules (support ≥ 1%, lift ≥ 2) |

**Honest caveats** (see the report, §10): anonymous transactions are excluded from customer analytics (13.572% of gross revenue); the 90-day churn label is a proxy; the dataset is one retailer and one year; and the ROI is a churn-conditional scenario analysis, not measured uplift: the conservative validated pilot net is GBP 14802.58, the model-precision figure is an optimistic bound, and the dataset contains no campaign history.

## Reproduce the analysis

1. **Get the data** (23 MB, not committed to git):

   ```bash
   python data/download_data.py
   ```

   This downloads the UCI Online Retail `.xlsx` into `data/` and validates the row count. You can also download it manually from <https://archive.ics.uci.edu/dataset/352/online+retail>.

2. **Install dependencies** (Python 3.10+):

   ```bash
   pip install -r requirements.txt
   ```

3. **Run the notebook from a fresh kernel**:

   ```bash
   jupyter nbconvert --to notebook --execute --inplace notebooks/CDS3004_Project.ipynb
   ```

   or open it in Jupyter and choose *Restart & Run All*. The full pipeline takes well under ten minutes on a laptop CPU (about 27.5 seconds in the recorded run) and writes every figure, table and metrics file in `results/`. In Google Colab, the setup cell installs `mlxtend` automatically if it is missing.

4. **Expected output:** `results/figures/*.png`, `results/tables/*.csv`, `results/metrics.json`, `results/metrics_extra.json`, `results/metrics_summary.md` and `results/ARTIFACTS.md`. Running from a clean environment regenerates the numbers quoted in the report.

Seeds are fixed (`random_state = 42`) so results are deterministic given the library versions; minor last-decimal differences across operating systems or scikit-learn versions are possible.

## AI-usage disclosure

This project was built with AI agents as accelerators, not authors. Every task followed the human–agent workflow **human defines → agent proposes → human reviews → agent implements → human verifies → revise**, and every agent output was checked before it entered the notebook, report or slides. Each member's agent-use trajectory (prompts, proposals, human decisions, verification and commit evidence) is in [`agent-logs/`](agent-logs/), with an explanation of the evidence standard in [`agent-logs/README.md`](agent-logs/README.md) and a filled example in [`agent-logs/EXAMPLE_member1.md`](agent-logs/EXAMPLE_member1.md).
